# Tiger! Tiger! in Haskell

This is a completely pure simple 2d game made in Haskell. The game itself is intended to be a port of Tiger! Tiger! from Xenoblade Chronicles 2, all credit to the original developers, but I also strayed from their design in certain places.

As a project, I made it to learn more about designing and structuring a project in a functional paradigm. I thought it would be a complete nightmare, but it actually ended up suprisingly easy and I honestly think I prefer structuring projects this way now.
